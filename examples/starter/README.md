# Session Desk starter

These are source templates for the neutral six-scene broadcast. They use local charcoal and silver CSS, typographic identities, and no image assets.

Generate a bundle with `tools/render_tournament.py`. The CLI defaults to this starter; `--template piphound` selects the illustrated showcase.

Do not open these HTML source files as finished scenes. Rendering replaces their single data marker with a validated snapshot.

See [starter instructions](../../docs/STARTER.md) for template selection, output files, editing, and verification limits.

The data helpers in `broadcast.js` intentionally match `examples/tournament/broadcast.js`. A regression test rejects semantic drift between the presentations.
