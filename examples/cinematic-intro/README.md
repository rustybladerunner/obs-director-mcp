# The Trading Table: simulation opening

An original 24-second PipHound title sequence. The master canvas is 1920 x 1080,
16:9, at 30 frames per second. Charcoal, warm gold and bronze remain the palette.
The emotional spine: a glamorous trading table reveals its artificial world,
then PipHound takes the host's seat.

## Local preview

Keep this directory beside `../tournament/piphound-emblem.png`. Open `intro.html`
in a browser that permits local JavaScript and WebGL. The local Three.js bundle
needs no CDN, server or network connection. Its MIT license and verified source
provenance are in `vendor/`.

For an OBS Browser Source, use the local file URL with `?obs=1&silent=1`, set
1920 by 1080 and 30 frames per second, and reload to replay the opening. The
query hides controls and disables sound. Adding a Browser Source does not start
any recording or stream. After the title holds, select your Starting Soon scene.
The page does not change OBS scenes or control outputs by itself.

Use `?freeze=11.8&silent=1` for a fixed inspection frame; supported times are
0 through 24 seconds. Normal browser controls provide replay and sound toggles.
Reduced-motion preference displays the final title without sound or animation.
If WebGL is unavailable, the controls identify a basic Canvas preview. That
fallback does not establish acceptance of the 3D rendering.

The player can use a local `score.ogg` once an original score has been generated
and reviewed. That audio file is not supplied in this candidate. Missing or
blocked audio leaves the picture running silently. Rendering and playback tests
do not establish music quality or soundtrack synchronization.
