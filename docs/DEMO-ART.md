# Demo artwork

The Funded Desk background and frame are original generated sample assets.
Their complete prompts ship with the template. The palette refers to the
public TradeFunded site as viewed on 2026-10-08. No logo or slogan is copied.

The PipHound portrait uses the operator's revised, slimmer dog reference.
The operator supplied this reference, described it as a Grok image, and
authorized PipHound for the demo. The reference file and local paths are not
distributed. The overlay uses a generated background-removal result.
The visible movement is a small CSS transform of a still image, not generated
speech, lip synchronization, or a live camera. All chart values are synthetic.

## Presenter background-removal prompt

Edit the supplied PipHound dog artwork for a livestream overlay. Make ONLY one change: remove the plain white background and replace it with true alpha transparency. Preserve the supplied slimmer dog's exact silhouette, narrow head and neck proportions, facial expression, head tilt, white fur, caramel patch around the viewer-right eye, eyes, nose, goggles, leather collar, brass pendant, painterly texture, lighting, pose, size, and framing. Do not broaden the face, muzzle, neck, or shoulders. Do not redraw, beautify, stylize further, add elements, add shadows, or change the character. Keep both ears and all visible fur edges intact. No text. Preserve the original landscape canvas and character placement, with transparent pixels surrounding the cutout.

Images were generated with the built-in image-generation tool. Output model
details were not exposed by the tool. These sample assets are included with
this MIT project; third-party brand names remain their owners' marks.
